title: cmdk
---

:::warning
These bindings target Partas.Solid 2.x on Solid 1.9 and have not been ported to Solid 2 yet.
:::

`Partas.Solid.Cmdk` binds [cmdk-solid](https://cmdk-solid.vercel.app/), a command menu. See its docs for usage.

## Differences

`useCommandState` is bound, but its return value is not typed yet.

## Example

[Partas.Solid.UI](https://github.com/shayanhabibi/Partas.Solid.UI) has a command menu built on this binding.
