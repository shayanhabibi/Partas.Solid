---
title: Partas.Solid.UI
---

:::warning
These bindings target Partas.Solid 2.x on Solid 1.9 and have not been ported to Solid 2 yet.
:::

[Partas.Solid.UI](https://github.com/shayanhabibi/Partas.Solid.UI) is a component library written with Partas.Solid.
Its components are built on headless UI bindings such as [Kobalte](kobalte.md) and [cmdk](cmdk.md), and styled with
Tailwind CSS.

The repository is also the largest worked example of Partas.Solid, the bindings and [Storybook](storybook.md) used
together.
