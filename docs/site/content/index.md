# Partas

Open source F# front-end projects, built on [Fable](https://fable.io/) and [Solid](https://www.solidjs.com/).

## Partas.Solid

An F# DSL and Fable compiler plugin for Solid. You write components in F#, and the plugin compiles them to the JSX
Solid expects. Version 3.0 targets Solid 2.

→ [Get started](guide/index.md)

## Partas.Solid ecosystem

F# bindings for Solid libraries and components, including a port of shadcn/ui.

→ [Ecosystem](ecosystem/index.md)

## Partas.AnimeJs

F# bindings for [anime.js](https://animejs.com/).

→ [Partas.AnimeJs on GitHub](https://github.com/shayanhabibi/partas.animejs)
